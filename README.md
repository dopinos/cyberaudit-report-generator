# CyberAudit Report Generator

A lightweight tool for generating structured security audit reports.

## Features

- Project and client information
- Audit scope
- Security findings
- Severity classification
- Evidence documentation
- Security recommendations
- HTML report generation

## Purpose

CyberAudit Report Generator is designed to help security professionals
organize findings from authorized security assessments and produce
structured reports.

## Usage

Run:

python main.py

Then enter the project information and security findings.
